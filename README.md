# Pressure-Sensor-System
•	Developed a pressure-sensing system for a backhoe loader hydraulic feature to accurately determine and monitor real-time hydraulic pressure.<br>
•	Modelled sensor input and control response in Simulink, validating pressure-detection logic under varying hydraulic load conditions.<br>
•	Contributed to integration and testing of the pressure sensor with the vehicle's control system to ensure accurate, reliable readings.
